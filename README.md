# 🎒 NSUT Lost & Found

> A centralized, community-driven web platform to report, search, and reclaim misplaced items across the Netaji Subhas University of Technology (NSUT) campus.

---

## 📌 Problem & Solution

* **The Problem:** Misplacing items in lecture halls, the library, or food courts leaves students relying on fragmented WhatsApp groups and physical notice boards where posts get lost quickly.
* **The Solution:** **NSUT Lost & Found** provides a single, searchable digital hub. Students and faculty can report found items with pictures and location tags or search for lost belongings in real time.

---

## ✨ Key Features

* 🏷️ **Categorized Listings:** Sort by category (IDs/Documents, Electronics, Books, Accessories) and campus locations (Block 1–6, Central Library, Food Courts, Audi).
* 🔍 **Instant Search:** Search items by keywords, date ranges, or status (Unclaimed, Claimed).
* 🛡️ **Verified Claim System:** Built-in ownership verification to ensure items are returned safely to their rightful owners.
* 📱 **Mobile First:** Designed to load fast over campus Wi-Fi networks.

---

## ⚙️ Implementation & Architecture

* 🐍 **Python Backend:** Built a lightweight and scalable server-side environment completely using **Python**.
* ⚡ **Flask Deployment & API Routes:** Created a structured **Flask application** with dedicated routes handling HTTP methods (`GET`, `POST`, `PUT`, `DELETE`) to process incoming user requests and serve API endpoints.
* 🔗 **Frontend-Backend Integration:** Connected the interactive user interface seamlessly with backend APIs to handle real-time data flow for submitting, searching, and updating item statuses.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python, Flask (RESTful APIs)
* **Database:** SQLite / PostgreSQL
